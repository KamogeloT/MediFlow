BPM Feature Test

1. Check if you're logged in as a Doctor

Open your browser's Developer Tools (F12) and check the Console tab for:

  • User ID
  • User Role
  • Queue Items count
Expected: You should see "User role: doctor" and some queue items

2. Check if BPM Buttons are Visible

Look for these buttons in your patient queue:

  • For waiting patients: "Start Consultation" button (blue outline)
  • For in-consultation patients: "Continue Consultation" button (blue outline)
Note: These buttons only appear if you're logged in as a doctor

3. Test BPM Panel

Click "Start Consultation" on any waiting patient. You should see:

  • The BPM consultation panel opens
  • Tabs for: Consultation, Workflow, Routing, Audit Logs
  • Input fields for notes, diagnosis, prescription
  • Options to complete, route, or archive

4. Common Issues & Solutions

No patients visible?
- Check if you have patients in the queue table
- Run the test data script: add_test_data.sql
BPM buttons not showing?
- Check console for user role
- Make sure you're logged in as a doctor
- Check if there are patients with 'waiting' or 'in-consultation' status
BPM panel not opening?
- Check console for errors
- Make sure BPMConsultationPanel component is imported correctly
